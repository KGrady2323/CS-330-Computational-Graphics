CS 330 Computational Graphics and Visualization Portfolio

3D Living Room Scene

For my CS 330 final project, I worked on creating a 3D living room environment using C++ and OpenGL. My goal was to recreate a scene from the perspective of someone sitting on a couch and looking toward a coffee table and television. Throughout the project, I worked with basic 3D shapes, transformations, textures, lighting, and camera navigation to make the environment more realistic and interactive.

1. How do I approach designing software?

Working on this project helped me better understand how important planning is when designing software. I started by choosing a living room scene and identifying the different objects I wanted to recreate. Instead of trying to build everything at once, I broke the scene down into smaller objects that could be created using basic 3D shapes.

One of the biggest things I learned was how scaling, rotation, and positioning affect the appearance of objects in a 3D environment. I also learned that even simple shapes can create more complicated objects when combined correctly. In future projects, I plan to continue breaking larger problems into smaller tasks before starting the coding process.

2. How do I approach developing programs?

My approach to programming has changed throughout this course because I have become more comfortable testing and adjusting my code as I work. While developing my 3D scene, I worked on different features during each milestone, including creating objects, implementing camera controls, applying textures, and adding lighting.

One challenge I experienced was getting textures to load correctly. I had to review file paths and troubleshoot errors when certain textures were not appearing in the scene. This taught me the importance of checking small changes before moving forward.

I also learned that developing a program takes multiple attempts and adjustments. Instead of expecting everything to work immediately, I became more comfortable using error messages and testing to identify problems. This is something I plan to continue doing in future programming projects.

3. How can computer science help me in reaching my goals?

Computer science is helping me build the skills I need to pursue a career in software development. This course introduced me to a different side of programming by showing how code can be used to create and interact with visual environments.

Working with OpenGL helped me better understand how mathematics, programming, and graphics work together. I gained experience using coordinates, transformations, lighting, and camera movement to create a 3D environment.

Even if I do not end up working directly in computer graphics, I believe the problem-solving and debugging skills I developed will be useful in other areas of software engineering. This project also gave me another example of my programming work that I can show future employers as I continue building my portfolio.
